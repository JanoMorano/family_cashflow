# Family Cashflow Changelog

## 1.1.1 - Family Cashflow 1.1.1

- Added editable gas tariff price-list fields and monthly average utility cost calculation refinements.

## 1.1.0 - Family Cashflow 1.1

- Added login and multi-user session support with default `admin/admin` and `demo/demo` accounts.
- Added profile dialog for password changes and selecting a user's primary budget column.
- Added simultaneous-editing support with data versions, conflict detection, and live update notifications.
- Added gas tracking alongside electricity, including readings, tariff, import/export, and Innogy PDF pricing.
- Added interactive month picker, automatic first-day month copy, and month history page with income/expense differences.
- Linked savings rows with savings/fund cards and added delete lock protection.
